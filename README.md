# KDYNN Market

Modern Next.js rebuild for KDYNN Market in San Jose del Monte, Bulacan.

## Stack

- Next.js
- React
- TypeScript
- Modern CSS
- Lucide React
- Vercel deployment

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Notes

The inquiry form opens the visitor's email client with a pre-filled message addressed to `azuleermenu@gmail.com`. No API key or secret is exposed in the browser.
